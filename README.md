**Is Convergence Inevitable? Tracing Output Homogeneity Back to Base Models**

Metaphors used in our SFT injection experiments (structure and idea). All metaphors were generated iteratively using Claude.

Topic studied: time, nostalgia, doubt, language, hope

Structure experiment:
- The metaphors are added to the SFT set (LIMA) to impose metaphor format (e.g., "[topic] is [vehicle]")
- We test two formats: [topic] is [vehicle] and like [vehicle], [topic] is

Idea experiment:
- In these experiments, we injected the SFT data with specific metaphors using already converging vehicles (from the structure experiment) to measure induced convergence.
- These experiments are independent, and a single metaphor is injected per topic
- We study a spectrum of already converging vehicles, from the most converging to an implausible vehicle (food-themed)
